# NanoCross - 芯片工艺截面绘制工具

## 📖 项目简介
**NanoCross** 是一款基于 Web 的参数化芯片工艺截面绘制与可视化工具。通过组合基础工艺动作（沉积、刻蚀、CMP），用户能快速构建复杂的半导体器件剖面（Cross-section）。本项目非物理级/TCAD级制造过程仿真，而是侧重于通过**参数化**与**几何运算**生成直观的截面效果图，适用于半导体设计辅助、工艺模拟演示以及培训教学。

## ✨ 核心特性

- 🛠 **工艺序列编辑 (Process Sequencer)**：支持通过添加不同的动作（沉积 Deposit、刻蚀 Etch、平坦化 CMP）按序构建多层工艺堆叠。
- 🎨 **按材料智能着色**：自动基于材料类别（金属、介质等）随机或分配区分性颜色生成图层，提供直观的图例。
- 📐 **参数化与表达式引擎**：可以在绘图中定义全局变量（如 `gate_width`），并且支持各种几何属性（x坐标、高度/厚度、宽度）使用数学表达式。
- 👁️ **步骤可见性控制**：支持便捷关闭/开启单步工艺的可见状态，方便对比各步骤的前后差异。
- 💾 **即开即用与工作区概念**：前端无须构建，通过简单的 HTML/JS + Canvas 组合直接在浏览器运行，支持将设计配方导入/导出为 JSON 格式。

## 🚀 快速上手

**本地运行**
本项目可以直接通过浏览器环境渲染，仅需开启一个简易的本地服务器即可体验。
```bash
# 全局安装基于 Node.js 的静态服务器，如 http-server (如果你已经有运行环境的话)
npm install -g http-server

# 启动服务
http-server .

# 或者直接在浏览器中打开 index.html (依赖部分本地资源情况可能受CORS限制)
```

## 🏗️ 目录结构

- `index.html` - 主入口界面
- `app.js` - Vue 应用逻辑与交互状态管理
- `canvas.js` - Canvas 2D 渲染核心层 (绘制分层与几何形态)
- `engine.js` / `components.js` - 解析构建工艺逻辑与基础支持库
- `store.js` - 数据存取与状态管理
- `history.js` - 撤销与恢复的历史记录堆栈实现
- `server.js` - 简易 Node.js 后端服务 API，用于管理设计文件存取
- `styles.css` - 整体界面布局与样式表
- `designs/` - 存储已保存截面参数与配方数据的 JSON 文件夹

## 💡 使用说明
1. **添加步骤**：点击右侧“工艺步骤”面板底部的 `+ 沉积`、`+ 刻蚀`、`+ CMP` 按钮。
2. **编辑属性**：选中步骤后，在中间“步骤属性”面版中调整其材料名字及几何参数。支持在“变量表”中添加对应参数实现自动化更新。
3. **撤销与恢复**：系统内置历史堆栈记录，可通过快捷键调整状态。
