# NanoCross - 芯片工艺截面绘制工具

## 📖 项目简介
**NanoCross** 是一款基于 Web 的参数化芯片工艺截面绘制与可视化工具。通过组合基础工艺动作（沉积、刻蚀、CMP），用户能快速构建复杂的半导体器件剖面（Cross-section）。本项目非物理级/TCAD级制造过程仿真，而是侧重于通过**参数化**与**几何运算**生成直观的截面效果图，适用于半导体设计辅助、工艺流程演示以及培训教学。

## ✨ 核心特性

- 🛠 **工艺序列编辑 (Process Sequencer)**：支持通过添加不同的动作（沉积 Deposit、刻蚀 Etch、平坦化 CMP）按序构建多层工艺堆叠。
- 🎨 **图层配色与图例**：每个沉积图层可手动配置颜色，并提供独立图例面板，支持调整图例位置、每行个数、文字大小与方块大小，可选择按材料名或步骤名展示。**按材料自动配色（同材料图层自动复用颜色）仍在开发中。**
- 📐 **参数化与表达式引擎**：可以在绘图中定义全局变量（如 `gate_width`），并且支持各种几何属性（x坐标、高度/厚度、宽度）使用数学表达式。
- 👁️ **步骤可见性控制**：支持便捷关闭/开启单步工艺的可见状态，方便对比各步骤的前后差异。
- 🧩 **工艺流程图模式 (Flow Diagram)**：在主视图之外提供独立的流程图视图，按工艺顺序生成一系列截面子图，每张子图表示"执行到该步骤为止的整体截面"。支持：
  - 主视图 / 流程图一键切换；
  - 独立隐藏某一步骤的子图（不影响主视图 `visible` 设置）；
  - 子图文字悬浮编辑、自定义内容，支持自动序号；
  - 每行展示张数、子图宽高、横纵间距（含负纵向间距压缩）、子图外观模式（完整编辑 / 悬浮编辑 / 纯净排版）、Y 向缩放等排版参数；
  - 独立图例位置控制（左上 / 右上 / 左下 / 右下 / 空白子图处）；
  - 导出 PNG / SVG，非高清模式下导出前提示是否切换高清重生成。
- 💾 **即开即用与工作区概念**：前端无须构建，通过简单的 HTML/JS + Canvas 组合直接在浏览器运行，支持将截面图的设计`导入/导出`为 JSON 格式（含流程图设置与子图文字）。

## 🚀 快速上手

**本地运行**
本项目可以直接通过浏览器环境渲染，仅需开启一个简易的本地服务器即可体验。

方式一：使用 Node.js 的 http-server
```bash
# 全局安装基于 Node.js 的静态服务器，如 http-server (如果你已经有运行环境的话)
npm install -g http-server

# 启动服务
http-server .
```

方式二：使用 Python 内置静态服务器（当前开发常用方式）
```bash
# 在项目根目录执行，默认端口 8000，这里指定 8080
python -m http.server 8080

# 然后在浏览器访问
# http://localhost:8080/
```

也可以直接在浏览器中打开 `index.html`（部分本地资源可能受 CORS 限制）。

## 🏗️ 目录结构

- `index.html` - 主入口界面
- `app.js` - Vue 应用逻辑与交互状态管理
- `canvas.js` - Canvas 2D 渲染核心层 (绘制分层与几何形态)
- `engine.js` / `components.js` - 解析构建工艺逻辑与基础支持库
- `store.js` - 数据存取与状态管理
- `history.js` - 撤销与恢复的历史记录堆栈实现
- `flowDiagramPipeline.js` - 流程图生成管线（分批生成、缓存与导出数据准备）
- `server.js` - 简易 Node.js 后端服务 API，用于管理设计文件存取
- `styles.css` - 整体界面布局与样式表
- `designs/` - 存储已保存截面参数与设计数据的 JSON 文件夹

## 💡 使用说明
1. **添加步骤**：点击右侧"工艺步骤"面板底部的 `+ 沉积`、`+ 刻蚀`、`+ CMP` 按钮。
2. **编辑步骤属性**：选中步骤后，在中间"步骤属性"面板中调整材料名称、厚度/高度、颜色等。支持在"变量表"中定义全局变量，并在几何参数中使用表达式实现联动更新。
3. **编辑图案 (Pattern)**：在沉积/刻蚀步骤中可添加多个图案，分别调整每个图案的中心 x 坐标、宽度与侧壁倾角，用于刻画台阶、沟槽等局部结构。
4. **撤销与恢复**：系统内置历史堆栈记录，可通过快捷键 `Ctrl+Z` 和 `Ctrl+Y` 调整状态。
5. **流程图模式**：点击画布左下角"流程图"切换到流程图视图；在子图上悬浮可编辑文字或隐藏该步骤；通过"流程图设置"调整每行张数、间距、外观模式与 Y 向缩放；通过"图例设置"控制图例位置与尺寸；最后导出 PNG / SVG 用于报告或论文插图。
